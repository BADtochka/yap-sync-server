# YAP Sync Server

Опциональный сервер синхронизации YAP для локальной сети. На каждом устройстве выбирают одну папку медиатеки для отправки и получения треков. Сервер хранит файлы по SHA-256 и JSON-снимки устройств. YAP объединяет плейлисты, метаданные и счётчики локально.

## Установка

В YAP откройте **Настройки → Инструменты → Сервер YAP Sync** и нажмите **Установить**. Клиент выбирает файл для вашей платформы из [релиза](https://github.com/BADtochka/yap-sync-server/releases) и сверяет SHA-256 перед запуском.

## Сборка из исходников

Соберите автономный бинарник с Go 1.24 или новее.

```sh
go test ./...
go build -trimpath -o yap-sync-server .
```

На Windows укажите имя `yap-sync-server.exe`. Для ручной установки в YAP выберите **Другой источник**, затем укажите бинарник или ссылку на файл GitHub Releases. В поле SHA-256 укажите хеш файла. Для релизов он есть в `SHA256SUMS`. Для локальной сборки используйте `shasum -a 256 yap-sync-server`, `sha256sum yap-sync-server` или `Get-FileHash .\yap-sync-server.exe -Algorithm SHA256`.

## Подключение устройств

Включите сервер YAP Sync в **Настройки → Инструменты** на одном компьютере. Сервер запускается автоматически вместе с YAP и выбирает основной сетевой адаптер. В настройках инструмента показаны адрес и список доступа.

На другом устройстве откройте настройки инструмента, нажмите **Найти в сети** и выберите сервер по имени и адресу. Выберите папку медиатеки и нажмите **Подключиться**. На хосте YAP покажет имя устройства и предложит разрешить или отклонить подключение. После разрешения синхронизация начнётся автоматически.

Протокол поиска использует UDP 38738 на основном IPv4-адаптере. Обмен идёт по HTTPS на TCP 38737. В ручном режиме можно указать другой TCP-порт. Для прохождения штатного сетевого экрана разрешите эти порты в локальной сети.

## Хранение данных

Каталог сервера содержит аудио, состояние устройств, список доступа и ключ управления. Список доступа сохраняется между запусками. Новые устройства получают доступ после явного одобрения. Отзыв закрывает последующие запросы этого устройства. При изменении IP заново выберите сервер в результатах поиска.

Автономный бинарник можно запустить отдельно. В первой строке он выводит параметры подключения для клиента. Для управления таким экземпляром есть HTTPS API `/v1/admin/devices`, защищённый полем `admin` файла `identity.json` из его каталога данных.

```sh
./yap-sync-server --listen 192.168.1.20:38737 --data ./sync-data
```

## Релизы

Workflow `.github/workflows/release.yml` по тегу `v*` публикует файлы для macOS, Windows и Linux на AMD64 и ARM64, а также `SHA256SUMS`. Обновление встроенного установщика в YAP требует закрепить новый тег и SHA-256 релиза.
